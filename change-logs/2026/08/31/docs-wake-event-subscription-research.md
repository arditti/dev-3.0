Research document for a central WAKE/event-subscription mechanism: agents subscribe to external events (GitHub activity, CI, deploys, timers, custom CLI emits) at task/project/space/global scope and are woken with structured envelopes. Covers the existing signal-path survey, subscription/waker/filter model, delivery policies, queueing semantics, open-source verdicts, migration impact, and a staged plan. No code changes.
