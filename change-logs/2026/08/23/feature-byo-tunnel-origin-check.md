Short: Remote access behind any tunnel

First step toward bring-your-own-tunnel remote access (ngrok-style providers alongside the built-in Cloudflare quick tunnel): the remote-access origin check now also accepts an Origin matching X-Forwarded-Host, so Host-rewriting tunnel proxies no longer break browser auth and WebSocket upgrades. A custom provider is configured in Settings → System, and its edge readiness and ongoing health are verified by probing the public URL it prints, rather than trusting that a live process means a live tunnel. A provider that hands out the same hostname twice in a row is remembered as stable, which lets a self-update stop and respawn its tunnel instead of leaking the process across the restart.
