Fixed locally built dev-channel apps opening a permanently black window on macOS: the dev-only DevTools auto-open at dom-ready hit a known Electrobun bug (blackboardsh/electrobun#357) where the docked Web Inspector corrupts WKWebView content rendering — a fully black window on macOS 26 while the renderer keeps running. DevTools auto-open is now platform-gated off on macOS (still on for Linux/Windows), with `DEV3_DEVTOOLS=1`/`=0` as explicit overrides, restoring native-window development on macOS.
