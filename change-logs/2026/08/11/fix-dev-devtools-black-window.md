Fixed locally built dev-channel apps opening a permanently black window on macOS 26: the dev-only DevTools auto-open at dom-ready hit a known Electrobun bug (blackboardsh/electrobun#357) where the docked Web Inspector blanks WKWebView content rendering while the renderer keeps running. DevTools auto-open is now gated off on macOS 26 and newer (still on for Linux, Windows, and earlier macOS), with `DEV3_DEVTOOLS=1`/`=0` as explicit overrides, restoring native-window development on macOS 26.
