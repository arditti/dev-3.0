5 · Agents managing their own crons — pure CLI, no UI needed

The agent-facing flow the shipped skill teaches: subscribe, list, receive the envelope, unsubscribe. The same subscriptions appear in every control-center mount above.

Etiquette the skill enforces: subscribe when a wait begins, unsubscribe when the reason is gone, prefer digest/debounce for chatty sources, and never manage wider-scope subscriptions without raising attention to the user.
